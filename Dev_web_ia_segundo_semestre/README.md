# Desenvolvimento Web e IA — Segundo semestre

Trabalhos e estudos de desenvolvimento web.

- **Desenvolvimento_Web:** páginas HTML, CSS e imagens do antigo `Segundo_semestre_Des_Web`. A branch `main` da origem está vazia; usamos `gh-pages` como base e guardamos `4-api` e `feat/nova-tela` em `branches/`.
- **Avaliacao_Frontend:** atividade com telas `index.html`, `sobre.html`, `exercicio.html`, CSS e JavaScript.
- **Estudos_Node_Express:** exemplos de Node.js/Express sobre servidor, cálculos, parâmetros de rota, query params e APIs de produtos com GET/POST.

## Executando exemplos Node.js

Dentro de `Estudos_Node_Express/`:

```powershell
npm install
```

Veja os scripts disponíveis em `package.json` antes de executar. Alguns exemplos possuem endpoints e portas próprios e devem ser iniciados individualmente.

Para os exercícios HTML, abra o arquivo correspondente no navegador ou utilize uma extensão de servidor local para desenvolvimento.
