# Exercícios — Primeiro semestre

## `Exercicios_C_CPP/`

Exercícios introdutórios de programação em arquivos `.cpp`, abordando condicionais, cálculos, descontos, conversões de unidades, juros simples, consumo de combustível e validação de valores.

Fonte original: [`-Exercises-at-university-in-C-`](https://github.com/Kaue-Borges/-Exercises-at-university-in-C-).

Para executar um arquivo, utilize um compilador de C++, por exemplo:

```bash
g++ "numero par ou impar (exercicio 3).cpp" -o programa
./programa
```

No Windows, o executável normalmente será `programa.exe`. O comando acima é apenas um exemplo; os nomes de arquivos contêm espaços.
