# Programação Orientada a Objetos — Segundo semestre

Exercícios e atividades em Java organizados pelo conteúdo e pela origem.

- **Jackson_Semana2:** pasta originalmente criada para a segunda semana. Na verificação inicial, continha somente `README.md`.
- **Exercicios_Jackson:** exercícios de calculadora, `switch`, `while`, tabuada e validação de idade.
- **Exercicios_21_09:** arquivos de exercício e classes relacionadas a aluno e produto.
- **Avaliacao_Java:** versão de avaliação com `Main.java`, `Robo.java` e README de imagens.
- **Campeonato_de_Robos:** arquivos `Main.java` e `Robo.java` extraídos da pasta `atividadeavaliativa` do repositório de exercícios de 21/09.

**Atenção:** `Avaliacao_Java` e `Campeonato_de_Robos` podem representar versões distintas de um exercício semelhante. Foram mantidas separadas para preservar o código, sem tentativa de mesclagem automática.

A execução depende do JDK e da organização das classes de cada exercício. Verifique se há declarações `package` antes de compilar com `javac`.
