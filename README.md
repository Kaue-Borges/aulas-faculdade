# Aulas e exercícios — Análise e Desenvolvimento de Sistemas

Repositório de atividades acadêmicas organizadas por semestre e disciplina. Os exercícios foram desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas** e abrangem programação, orientação a objetos, desenvolvimento web e estruturas de dados.

## Disciplinas e trabalhos

| Área | Conteúdo |
| --- | --- |
| [Exercícios do primeiro semestre](Exercicios_primeiro_semestre/) | Exercícios introdutórios de lógica e programação em C++ |
| [POO — segundo semestre](POO_Segundo_semestre/) | Fundamentos Java, exercícios de Jackson e simulações de robôs |
| [Desenvolvimento Web e IA — segundo semestre](Dev_web_ia_segundo_semestre/) | Exercícios HTML/CSS/JS, avaliação de frontend e estudos de Node.js/Express |
| [Estrutura de Dados — segundo semestre](Estrutura_de_dados_segundo_semestre/) | Atividades sobre estruturas e conceitos de lista, fila e pilha |

## Como usar

Acesse a pasta da matéria desejada e consulte o código e o README da disciplina. Alguns projetos são páginas HTML executáveis diretamente no navegador; outros exigem um ambiente Java, compilador C++ ou Node.js, conforme indicado nas respectivas pastas.

Este repositório reúne **trabalhos acadêmicos**, não um único aplicativo. As dependências e comandos de execução variam por exercício.

## Fontes e migração

Os trabalhos foram organizados a partir de repositórios individuais da conta [Kaue-Borges](https://github.com/Kaue-Borges), sem sobrescrever versões que possuíam nomes de arquivo semelhantes. Consulte [o mapa de origem](docs/MAPA_DE_ORIGEM.md).
